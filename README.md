## Project Timeline

This project focused on intensive learning experience, with each day focused on specific Java and software development concepts:

*   **Day 1: Git/GitHub/Git Bash:**  I learned the basics of version control using Git.  I practiced using Git Bash for command-line Git interactions and set up a GitHub repository to host my projects.  This was crucial for collaborating and managing code changes effectively.

*   **Day 2: Java Fundamentals (JVM/JRE/JDK):** I explored the Java platform architecture, understanding the roles of the Java Virtual Machine (JVM), Java Runtime Environment (JRE), and Java Development Kit (JDK). I learned how these components work together to execute Java code.

*   **Day 3: Java Basic Programming:** I covered the foundational elements of Java programming, including data types (int, float, boolean, etc.), variables, operators (arithmetic, logical, etc.), and basic input/output operations using `System.out.println()` and `Scanner`.

*   **Day 4: Java Flow Control:** I studied control flow statements, which are essential for creating logic in programs. This included `if-else` statements, `switch` statements, `for` loops, `while` loops, and `do-while` loops. I practiced writing code with conditional logic and iterative processes.

*   **Day 5: Java Arrays:** I learned about arrays in Java, which allow you to store collections of elements of the same data type. I practiced declaring, initializing, and accessing array elements, as well as working with multi-dimensional arrays.

*   **Day 6: Java Methods:** I focused on methods, which are reusable blocks of code. I learned how to define methods with parameters and return values, improving code modularity and organization.

*   **Day 7: Java Strings:** I was introduced to the `String` class in Java, which is used to represent text. I learned about string immutability and common string operations.

*   **Day 8: Java String Handling:** I explored various string manipulation techniques, including methods for searching, replacing, concatenating, and formatting strings.

*   **Day 9: Java OOPs:** I delved into the core principles of Object-Oriented Programming (OOP): encapsulation (bundling data and methods), inheritance (creating hierarchies of classes), and polymorphism (using objects of different classes interchangeably).

*   **Day 10: Java Constructors, Instance vs. Static:** I learned about constructors, which are special methods used to initialize objects. I also distinguished between instance variables (specific to each object) and static variables (shared by all objects of a class).

*   **Day 11: Keywords (this, static, final, instance):** I studied the important Java keywords: `this` (referring to the current object), `static` (indicating class-level members), `final` (making variables or methods immutable), and how these interact with instance members.

*   **Day 12: Class Relationships (Association, Aggregation, Composition):** I explored the different types of relationships between classes: association (a general relationship), aggregation ("has-a" relationship, where the related object can exist independently), and composition ("part-of" relationship, where the related object's lifecycle is dependent on the containing object).

*   **Day 13: Object Modeling and Class Diagrams:** I learned how to design object models and represent them visually using class diagrams. This helped me plan and structure my Java applications effectively.
